# Clinical Co-Pilot — fork of OpenEMR

This repository is a fork of [openemr/openemr](https://github.com/openemr/openemr) that adds a **Clinical Co-Pilot** — a source-cited AI agent embedded in the patient chart that produces a 90-second morning briefing for the next patient on a clinician's schedule and answers grounded follow-up questions about that chart. Every claim the model emits is verified against a typed `ChartSnapshot` before it reaches the UI; uncited claims are dropped at the gate, and every chart read is logged as a disclosure event.

The upstream OpenEMR README continues below this section.

## Demo deployment

- **URL:** [https://emr.biograph.dev](https://emr.biograph.dev)
- **Login:** see `docs/RUNBOOK.md`
- **Patients:** synthetic data generated by `db/seeds/seed-all.sh`; no real PHI on this host.

## Where the agent lives in the tree

```
/agent/                                     Node/TypeScript LangGraph runtime (private service)
/interface/modules/custom_modules/oe-module-clinical-copilot/
                                            OpenEMR-side proxy controller, token mint, snapshot endpoints, UI panel
/db/seeds/                                  Synthetic chart-deep data for the USERS.md scenarios
/docs/                                      Project documents listed above
/docker/digitalocean/                       Production compose stack (`emr.biograph.dev`)
/docker/development-easy/                   Local dev stack (OpenEMR + agent + agent-postgres)
```

## Quick start (local development)

```sh
# Bring up the full stack
cd docker/development-easy
docker compose up --detach --wait

# Sign in at http://localhost:8300/  (admin / pass)
# Agent service is on the private Docker network — exercise it through OpenEMR.
```

For agent-only iteration without the full stack, see [`agent/README.md`](agent/README.md).

# OpenEMR

[OpenEMR](https://open-emr.org) is a Free and Open Source electronic health records and medical practice management application. It features fully integrated electronic health records, practice management, scheduling, electronic billing, internationalization, free support, a vibrant community, and a whole lot more. It runs on Windows, Linux, Mac OS X, and many other platforms.

### Contributing

OpenEMR is a leader in healthcare open source software and comprises a large and diverse community of software developers, medical providers and educators with a very healthy mix of both volunteers and professionals. [Join us and learn how to start contributing today!](https://open-emr.org/wiki/index.php/FAQ#How_do_I_begin_to_volunteer_for_the_OpenEMR_project.3F)

> Already comfortable with git? Check out [CONTRIBUTING.md](CONTRIBUTING.md) for quick setup instructions and requirements for contributing to OpenEMR by resolving a bug or adding an awesome feature 😊.

