Final submission · what we built

Two compiled graphs, one citation contract, five rubrics blocking every PR.

A LangGraph supervisor over chart, document, and guideline retrievers; a separate ingestion graph that turns scanned PDFs into bbox-anchored facts; one polymorphic citation shape that the verifier resolves per source-type; a 5%-cell-flip eval gate that runs the real models against every suite on every MR.

3 Doc types — lab PDF, intake form, DOCX referral letter — same strict-Zod → page+bbox path.
723 Guideline chunks indexed dense+BM25 across USPSTF · ADA · CDC · AGS-Beers.
3 → 100 → 5 Query rewrites fan out to a 100-cap fused candidate set; rerank emits the final 5.
≤ 5% Per-MR regression-rate tolerance on (case × rubric) cells — real Anthropic, OpenAI, Cohere, Pinecone calls.
2 Dashboards coexisting — React/FHIR SPA next to legacy PHP, iframe-bridged for gradual cutover.

Slide 2 · The decisions worth defending

Hybrid retrieval, PHI-safe traces, eval gate — verifiable in code, not slides.

Each step below names a constant or file you can grep for. This is what tightened most since Thursday — guideline matching, bbox alignment, retrieval merge, log safety, and the CI threshold itself.

Hybrid retrieval inside evidenceRetriever

R1 Multi-query rewrite QueryRewriter emits 3 variants in a fixed enum: paraphrase · step_back · terminology. Original query joins them. 4 queries
R2 Pinecone hybrid · per query Dense (OpenAI text-embedding-3-large, 3072d) + BM25 sparse, fused server-side, namespace guidelines-v1. top-20 × 4
R3 Reciprocal Rank Fusion RRF_K = 60 (Cormack 2009); fused candidate set capped at RRF_DEFAULT_TOP_M = 100. ≤ 100 fused
R4 Cohere rerank-v3.5 Reranks against the original query, not the rewrites. Outage → degraded mode tags snippet, never silently fails. top-5
R5 Quote excerpt → verifier QUOTE_EXCERPT_CHARS = 1200 projected per snippet so the verifier can substring-match without re-fetching. ≤ 1200 chars

Guideline matching & bbox alignment

G1
Corpus expanded beyond USPSTF

302 USPSTF + 251 ADA + 162 CDC (incl. ACIP immunizations, STI, Million Hearts) + 16 AGS-Beers chunks — committed to agent/data/corpus/, BM25 stats fitted at boot.6d99a344c5fdb41d2a

G2
Supervisor manifest broadened

Supervisor prompt no longer assumes USPSTF — now lists every committed source so the LLM doesn't refuse ADA/CDC asks for being "out of corpus."ff2944d6e

B1
Vision bbox in API space, not DPI

Coords now emitted in the vision model's input space and rescaled to PDF page coords — the rasterizer DPI never reaches the overlay anymore.aaf22c627

B2
0..1000 integer grid + 8-int quad

Bbox is an 8-integer flat tuple [x1,y1,…,x4,y4] on a 0..1000 grid (thousandths of page width/height) — robust to skewed scans, and Zod rejects anything else.99eb8b631

B3
Tesseract bbox-snap + column-header guard

Post-vision, Tesseract OCR snaps the model's bbox to actual text positions; column-header bboxes are forbidden by prompt + post-check; overlay padding tightened.76ed78fc8aae92fa07

PHI-safe logging & the CI eval gate

P1
Trace scrubber covers free-text supervisor fields

scrubLlmTextForTrace() walks decision.reason · narration · args through scanForPhi() (key-based + regex SSN/phone/MRN) before they reach LangSmith metadata.

P2
Vision payloads opted out at the SDK boundary

LANGSMITH_HIDE_INPUTS=true + LANGSMITH_HIDE_OUTPUTS=true in production drop raw rasterized pages and extraction outputs at the trace-emit layer, not after.

P3
Pinned by a live PHI scanner test

evals/cases/no-phi/vision-traces.test.ts drives the pipeline with a synthetic-PHI fixture and fails CI if any name/DOB/MRN/SSN canary appears in the live LangSmith run.e0fd663de

E1
Per-MR gate: test:agent-evals-gate

GitLab CI job (.gitlab-ci.yml:242) runs every suite's experiment against real Anthropic/OpenAI/Cohere/Pinecone, pulls per-rubric scores from LangSmith, fails on regression. Path-scoped to agent changes.

E2
Threshold: REGRESSION_RATE_TOLERANCE = 0.05

5% of (case × rubric) cells may flip true→false vs baselines/eval-suite.json. Cell-level, not bundled — a single rubric regressing on a single case counts.

E3
Skip-on-null instead of fan-fail

When a target throws, only factually_consistent fails; the other four rubrics skip with applicability="unknowable" so one upstream regression no longer flips 5 cells and corrupts the gate.8b2cd7f3e

E4
Cost & outage discipline

evals:check-cost aborts the gate above $5/PR; evals:vendor-health excludes outage cases from the denominator and surfaces them in the MR comment instead of failing the merge.

Slide 3 · Surprise challenge

React/FHIR SPA mounted as a second entry point — legacy untouched, gradual cutover real.

Chose coexistence over big-bang. The new dashboard owns top-level + patient-level navigation; sub-pages we haven't ported yet render in iframes that talk to the SPA shell through legacy-event shims.

Implemented

D1
SMART-on-FHIR / OAuth2 with EHR-launch pass-through

SPA authenticates via the OpenEMR OAuth2 server with fhirclient; when an OpenEMR session is already live, SMART EHR Launch skips the OAuth round-trip entirely.

D2
Persistent patient header on FHIR

Name · DOB · sex · MRN · active status pulled live from Patient; the React shell renders it once and routes both native cards and iframed legacy pages underneath.

D3
Five FHIR-backed clinical cards

Allergies · Problem List · Medications · Prescriptions · Care Team — each consumes the FHIR resource directly, with first-class loading and empty states.

D4
+1 chosen sections: Recent Encounters & Lab Results

Recent Encounters is the required +1; Lab Results landed as a stretch card that consumes the same Observation-trend data the agent uses for in-chat charts.

D5
Co-Pilot tab inside the new dashboard

The agent ships into the modernised UI on day one rather than waiting for cutover — chip click-through opens document and guideline drawers, same as the legacy panel.

D6
PATIENT_DASHBOARD_MIGRATION.md

Defends the React 19 + Vite + TanStack Router + fhirclient choice, names the tradeoffs of running two dashboards in parallel, and maps every legacy capability to its new home.

The architectural bet

Entry point A Legacy PHP dashboard
  • Untouched server-rendered pages
  • Same auth, same session, same workflow
  • Available to every clinician on day one
Entry point B · new React SPA on FHIR (main_v2.php shell)
  • Top-level + patient-level nav as React
  • Native cards over OAuth2 + FHIR
  • Co-Pilot tab embedded natively
Bridge: sub-nav pages we haven't ported yet render in iframes inside the SPA shell, talking to the host through shims that mirror legacy top.restoreSession(), patient-switch, and parent.left_nav events — gradual section-by-section rebuild, full workflow available from either entry point.
React 19 + Vite Fast HMR, modern hooks, small build surface for the SPA shell.
TanStack Router Type-safe routes; integrates cleanly with patient-uuid hooks and OAuth callback.
fhirclient + Medplum types Standards-based FHIR access; no bespoke client; types come from Medplum.
Slide 4 · What it costs to run

Cost scales with feature usage, not headcount — and the levers are explicit.

Engineering bill · doesn't scale with deployment tier

Per-MR eval gate · ~$6.42/run · $7.50 hard cap

92 cases across briefing-graph · conversational-graph · document-extraction against real Anthropic, OpenAI, Cohere, Pinecone. Path-scoped to agent diffs so doc/PHP-only MRs cost $0. check-cost-cap.ts aborts above $7.50 before any vendor call fires.

Steady-state at 50 MRs/month

Eval gate ~$320 · nightly experiment (30 runs) ~$190 · LangSmith Plus 3 seats + ~30K trace overage ~$132 = ~$640/month total, regardless of whether the deployment is 100 clinicians or 100,000.

Two cost forcing-functions in code

check-cost-cap.ts — $1.00 hard cap per document extraction, $7.50 hard cap per gate run. recordModelUsage — every model call writes exact token counts and per-model cost, so projection becomes measurement after one sprint of real traffic.

The thread: a clinician who never opens the panel produces zero tokens, zero JWTs, zero rows. Cost scales with adoption, not headcount — a 10,000-employee hospital with a 200-clinician pilot pays the 200-clinician bill. Full breakdown in docs/COST_ANALYSIS.md.

Slide 5 · What's new

Six tightenings since the early submission — each addresses a specific piece of feedback.

1
Tightened clinical-guideline matching

Multi-query rewrite (paraphrase + step-back + terminology) → 4× hybrid fan-out → RRF fusion (RRF_K=60, top_M=100) → Cohere rerank-v3.5 against the original query → top-5 to synthesizer. Wider candidate pool, sharper top.61ac6f8c2

2
Improved bbox alignment

Three concrete fixes: vision coords now in API space (not rasterizer DPI), 0..1000 integer-grid 8-int quads (skew-tolerant), Tesseract OCR snap + column-header guard with tightened overlay padding.aaf22c62799eb8b631aae92fa07

3
Hybrid merge + rerank made directly verifiable

Constants are exported (PINECONE_HYBRID_TOP_K, RRF_K, RRF_DEFAULT_TOP_M) and pinned by the queryRewriting.test.ts eval case which proves multi-query beats single-query on a held-out paraphrase set — not just an internal improvement, an evaluated one.

4
PHI-safe logging, end to end

Scrubber now covers supervisor free-text fields before trace emit; vision inputs/outputs hidden at the SDK boundary in production; vision-traces.test.ts runs synthetic-PHI fixtures against the live LangSmith trace to prove no canary leaks.e0fd663de

5
CI thresholds spelled out, in code

REGRESSION_RATE_TOLERANCE = 0.05 in scripts/eval-gate.ts; gate compares against baselines/eval-suite.json per (case × rubric) cell; cost-cap aborts above $5/PR; vendor-outage cells are excluded from the denominator, never silently absorbed.

6
Skip-on-null hardens the rubric signal

When a target throws, only factually_consistent fails — the other four rubrics skip with "applicability unknowable" instead of fanning into 5 false flips. One real regression now produces one cell flip, not six.8b2cd7f3e

The thread: every change above tightened something the spec already asks for — retrieval recall (1, 3), citation faithfulness (2), log safety (4), eval gate verifiability (5, 6). Nothing new, everything sharper.
